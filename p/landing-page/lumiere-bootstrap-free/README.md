# LUMIÈRE — Jewelry Store Template

A multi-page jewelry / fine-goldsmith storefront template built with **Bootstrap 5** and **jQuery**.

| Page | File |
| --- | --- |
| Home 01 | `index.html` |
| Home 02 | `home-2.html` |

| Home 04 | `home-4.html` |
| Sustainability & Ethics | `about.html` |
| Journal | `blog.html` |
| Journal Entry | `single.html` |
| Collections | `collection.html` |
| Shop | `shop.html` |
| Product Detail | `product-detail.html` |
| Cart | `cart.html` |
| Checkout | `checkout.html` |
| Custom Services | `services.html` |
| Style Guide | `style-guide.html` |

All pages share a common navbar (with a **Pages** dropdown, grouped into Home / Shop / Pages, linking every page above) and footer, so you can browse the full template from any page.

## Structure

- `style.css` — design tokens (colors, fonts, spacing) and Bootstrap 5 theme overrides.
- `js/script.js` — jQuery-powered interactions (search overlay, cart drawer, product size selector).
- `js/cart.js` — jQuery-powered cart page (quantity steppers, line/order totals, remove item).
- `js/checkout.js` — jQuery-powered checkout page (payment method toggle, demo order submit).
- `images/` — template imagery.

## Stack

- [Bootstrap 5](https://getbootstrap.com/) (CSS + bundled JS, loaded via CDN)
- [jQuery](https://jquery.com/) (loaded via CDN)
- Google Fonts: Newsreader, Work Sans
- Google Material Symbols (icon font)
