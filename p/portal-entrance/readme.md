## Usage

1. Browse the subfolders to find a portal style you like.
2. Copy the folder into your project.
3. Adjust markup, text, and assets as needed.
4. Wire up links/forms to your own destinations.

These are starting points — expect to tweak styling, copy, and behavior.

## Conventions

- **Self-contained** — each example works by opening its `index.html` directly, no build step.
- **No external dependencies** unless noted in the example's own README.
- **Original assets** — avoid third-party images/fonts with unclear licensing.

## Adding a new example

1. Create a subfolder: `portal-entrance/<example-name>/`.
2. Add `index.html`, `styles.css`, and any assets.
3. Add a short `README.md` in the example folder.
4. Add it to the **Examples** table and the **Contents preview** above.
