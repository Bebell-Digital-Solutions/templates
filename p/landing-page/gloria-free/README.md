# Gloria — Fashion Store HTML Template (FREE Version)

Gloria is a clean, modern **Bootstrap 5** HTML template for fashion & apparel e-commerce
stores, converted from the original Gloria Figma UI Kit.

**This is the FREE version** and includes the **Home page only** (`index.html`), fully
coded and ready to use. A full **multipage PRO version** with 13 additional pages —
Shop, Product Details, Cart, Checkout, Wishlist, Blog, About, Contact, Login/Register
and more — is available from TemplatesJungle.

**HTML template by [TemplatesJungle](https://www.templatesjungle.com/)** — see the
[About TemplatesJungle](#about-templatesjungle) section below.

## Getting Started

No build step required — this is plain static HTML.

1. Unzip the package.
2. Open `index.html` in your browser, or serve the folder with any static web server.
3. Edit the HTML/CSS directly with any code editor.

## Customizing

All design tokens (colors, fonts, spacing) live at the top of `assets/css/style.css`
under `:root`. Fonts (Poppins + Yellowtail) load from Google Fonts in the page `<head>`.
